# Journey media

`journey.webm`, `journey.mp4`, `journey-poster.jpg` and `../og-image.jpg` are generated **placeholders**.
To use a real clip: download one from https://www.pexels.com/videos/ (dark, calm, at least 1920px wide), set `SRC` to it,
and re-run the four ffmpeg commands in `docs/superpowers/plans/2026-11-21-portfolio-journey.md` (Task 9, Step 2).
